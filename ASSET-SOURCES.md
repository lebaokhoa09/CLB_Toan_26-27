Input: public HQ preview https://cdn.freesound.org/previews/798/798340_97763-hq.mp3. Source and modifications also credited on the existing audio credits page.

Processing: +13.96 dB static gain, 0.75-second linear overlap at loop boundary, MP3 192 kbps / stereo / 48 kHz. - **Ending compass, v21-compass-7:** `dist/assets/compass-outline-gold.svg`, manually redrawn as SVG paths and circles from the user-provided `canva-outline-compass-icon-MAG-UaGJkJI.png`. Uses the existing interface gold `#dfc58f`, rounded 14-unit strokes, a transparent background and a 462 × 550 viewBox. No raster image is embedded. The existing ending timeline animates the replacement image in the same 64 × 64 CSS box using `object-fit: contain`.

- **Active voyage chart:** dist/assets/atlas/native-panel-1.webp through native-panel-3.webp, three native2048² cuts of one6144×2048render. Coastlines/borders derive from Natural Earth4.1.0 via world-atlas2.0.2 countries-50m.json (local copy and licenses included). See https://github.com/topojson/world-atlas and atlas/provenance.json. Authored navy mineral grain/violet facets/gold strokes are generated at native render resolution; not an upscale of the old image. Logical world9600×3200; no repeat. Projection includes southern ocean: Y=(85-lat)/180*3200.
- **Active voyage vessel:** dist/ship-model.js, authored opaque Three.js geometry and procedural512² wood/cloth maps. Three masts, eleven fixed sails, fine rope segments and dark wood/gold details. Actual model yaw follows the route, without image warping or pose crossfade. Stylized reconstruction rather than a pixel-identical extraction from the video. Main renderer uses a768² target for this small model; this is distinct from its geometry detail and is not a native4K raster claim.
- **Reference/fallback assets below:** retained for opening/questions, visual authority, and no-WebGL fallback. The normal voyage does not load the old voyage-v2/chart-clean.png, ship-clean.png or periodic panorama.

- Opening reference: user codex-clipboard-f348097b-68ff-417f-9dc0-4b36e099aa57.png. Opening background/title are earlier ImageGen edits; prompts in asset-prompts.json and PNG metadata. Title remains separately animated.
- Question background: exact user codex-clipboard-2130a0fc-e3bc-4aad-931d-1e19dc203fa6.png, unchanged RGB.
- voyage-v2/reference.png: exact latest user image2, codex-clipboard-b1d9b82b-c5ed-4013-97cd-b0c9428224fe.png,1672×941. Visual authority, not a stock asset.
- voyage-v2/chart-clean.png: built-in ImageGen object-removal edit of image2. Removes original craft, shadow and broad dashed route; reconstructs the map behind them. Native1672×941. The generated hidden geography is an illustration, not surveyed geographical data.
- voyage-v2/ship-clean.png: built-in ImageGen transparent extraction/re-render based on the same reference, followed by an alpha/framing cleanup edit. Native1254×1254 RGBA. Detailed rigid dark wood/cream sail vessel with true transparent gaps. Not a pixel-identical crop or rigged3D vessel. Fine matte residue is documented in provenance.json; the runtime alpha test discards faint background noise.
- voyage-v2/provenance.json: exact prompts, inputs, original tool output paths, dimensions and alpha inspection. No resolution upscale or pixel editing applied to these two assets.
- voyage-panorama/chart.png: two built-in ImageGen outpaint/edit passes from chart-clean.png, preserving the navy/violet/gold material while extending the empty Pacific margins. Native2172×724; not4K. Exact prompts and dimensions in voyage-panorama/provenance.json and embedded PNG metadata. Direct repetition retains a faint seam; the map material applies a static4% ocean-only boundary blend. Central geography and ship pixels are unaffected by that shader. This chart is decorative periodic art, not navigation data.
